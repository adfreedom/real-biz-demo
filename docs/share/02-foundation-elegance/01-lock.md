# 2.1 分布式锁的优雅实现

> 预计讲解时长：~5 分钟
> 部分：二、基础组件的优雅实现

Redisson 注解式分布式锁，业务方法加一个注解即可，无侵入。

![分布式锁注解使用](../images/lock-annotation.png)

## 要点

- 注解声明锁 key / 等待时长 / 租约时长
- AOP 切面统一兜底加解锁，业务代码不感知
- 对比手写 `try-lock-finally-unlock` 的繁琐
